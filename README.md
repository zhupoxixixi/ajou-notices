# 亚洲大学中文公告 · Ajou Notices

[打开网站](https://zhupoxixixi.github.io/ajou-notices/) · [更新记录](https://github.com/zhupoxixixi/ajou-notices/actions)

面向亚洲大学中国留学生及一般大学院研究生，汇总学校公开公告的中文要点。界面与 [Ajou Menu](https://zhupoxixixi.github.io/ajou-menu/) 保持一致，无需注册或登录。

## 主要功能

- **中文公告**：收录一般大学院、外国留学生、国际交流处、奖学金、图书馆等 10 个公开来源，提供摘要、资格条件、重要日期和官方原文。
- **搜索与筛选**：按关键词、适用对象、主题、来源及截止状态查找，支持近期视图与本机收藏。
- **截止状态与日历**：首页默认隐藏已结束事项；报名截止但活动仍在进行时保留活动状态。支持 ICS 日历订阅和单条日历下载。
- **导出与离线**：支持中文 Markdown、JSON 导出，添加到手机主屏幕后可查看已缓存公告。
- **外观设置**：深浅色、三档玻璃效果及本机背景图片。

## 自动更新

每日韩国时间 **08:17、12:17、18:17** 自动检查，使用 **GPT-6 Luna** 整理新增或变化内容。来源或翻译失败时保留旧摘要，检查时间和异常可在设置中查看。收藏与背景图片仅保存在当前浏览器。

仅收录公开公告，不包含 Portal、아주Bb 等登录后内容。中文为要点摘要，重要资格、日期和附件要求请以官方原文为准。
